# Smartphones

Aplicație Windows Forms pentru gestiunea modelelor de smartphone și a producătorilor.

## Funcționalități

- producătorii sunt citiți din `producatori.txt`, iar modelele din `Inregistrari.txt`
- lista modelelor într-un `DataGridView`
- adăugare și modificare în formulare separate, cu validare prin `ErrorProvider`
- ștergere cu confirmare
- meniu contextual pentru editare și ștergere

## Tehnologii

C#, .NET Framework, Windows Forms

## Rulare

Se deschide `Smartphones.sln` în Visual Studio și se pornește proiectul.
